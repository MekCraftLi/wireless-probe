# 硬件接线与电气规范 (Hardware Wiring Guide)

本项目由 **树莓派 Pico 2 (RP2350)** 与 **乐鑫 ESP32-C5 (Wi-Fi 6)** 两枚主控芯片协同工作，对外提供针对目标 ARM Cortex-M 芯片的高速无线调试接口。

---

## 一、 Pico 2 与 ESP32-C5 互联引脚定义 (QSPI 内部总线)

两芯片间采用 **4-bit Quad-SPI (6 线) + 2 根硬件流控握手线 + 公共地线 (GND)** 互联：

```
       [Pico 2 (RP2350)]                               [ESP32-C5]
      +-------------------+                           +-------------------+
      | GPIO 16 (Pin 21)  | ------------------------> | GPIO 4  (J3 Pin 8)| (SCLK 时钟线, 6.25MHz~50MHz)
      | GPIO 17 (Pin 22)  | ------------------------> | GPIO 5  (J3 Pin 9)| (CS 片选线, 低电平有效)
      | GPIO 18 (Pin 24)  | <-----------------------> | GPIO 6  (J1 Pin 7)| (D0 数据线 0 / MOSI)
      | GPIO 19 (Pin 25)  | <-----------------------> | GPIO 23 (J3 Pin 5)| (D1 数据线 1 / MISO)
      | GPIO 20 (Pin 26)  | <-----------------------> | GPIO 8  (J1 Pin 9)| (D2 数据线 2 / WP)
      | GPIO 21 (Pin 27)  | <-----------------------> | GPIO 9  (J1 Pin 10| (D3 数据线 3 / HOLD)
      |                   |                           |                   |
      | GPIO 22 (Pin 29)  | <------------------------ | GPIO 10 (J1 Pin 11| (READY 硬件握手: C5 缓冲就绪, 低有效)
      | GPIO 26 (Pin 31)  | ------------------------> | GPIO 13 (J3 Pin 14| (REQ 硬件握手: Pico 2 请求发送, 低有效)
      |                   |                           |                   |
      | GND (Pin 23/28/38)| ------------------------> | GND (公共地线)    | (★必须可靠相连★)
      +-------------------+                           +-------------------+
```

### 详细引脚映射表

| 信号名称 | Pico 2 GPIO | Pico 2 物理引脚 | ESP32-C5 GPIO | ESP32-C5 物理引脚 | 功能说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **QSPI_CLK** | **GPIO 16** | Pin 21 | **GPIO 4** | J3 Pin 8 | SPI 移位时钟 (Pico 2 主机输出) |
| **QSPI_CS** | **GPIO 17** | Pin 22 | **GPIO 5** | J3 Pin 9 | SPI 片选 (Pico 2 主机输出，低有效) |
| **QSPI_D0** | **GPIO 18** | Pin 24 | **GPIO 6** | J1 Pin 7 | 双向半双工数据线 Bit 0 / MOSI |
| **QSPI_D1** | **GPIO 19** | Pin 25 | **GPIO 23** | J3 Pin 5 | 双向半双工数据线 Bit 1 / MISO (避开 Strapping 7) |
| **QSPI_D2** | **GPIO 20** | Pin 26 | **GPIO 8** | J1 Pin 9 | 双向半双工数据线 Bit 2 |
| **QSPI_D3** | **GPIO 21** | Pin 27 | **GPIO 9** | J1 Pin 10 | 双向半双工数据线 Bit 3 |
| **FLOW_RDY** | **GPIO 22** | Pin 29 | **GPIO 10** | J1 Pin 11 | C5 就绪中断线 (C5 输出，Pico 2 输入，低有效) |
| **FLOW_REQ** | **GPIO 26** | Pin 31 | **GPIO 13** | J3 Pin 14 | Pico 2 请求中断线 (Pico 2 输出，C5 输入，低有效) |
| **GND** | **GND** | Pin 23/28/38 | **GND** | 开发板 GND | **公共参考地（必须连接）** |

> [!NOTE]
> * **D1 选择 GPIO 23 的原因**：ESP32-C5 的 GPIO 7 为芯片 Strapping 引脚（影响上电引导与时钟选择），移至 GPIO 23 可彻底杜绝上电误触发 Bootloader。
> * **REQ 选择 GPIO 13 的原因**：避开 ESP32-C5 默认的 UART0 下载串口引脚（GPIO 11），保证调试日志与烧录不受干扰。

## 二、 调试器连接目标芯片引脚定义 (SWD 调试输出)

Pico 2 的另一侧引出标准 SWD 与串口监视引脚，直接连接目标板（如 STM32、GD32、NXP 等）：

```
     [无线调试器 Pico 2 端]                 [目标板 (如 STM32H7 / F4 / F1)]
    +----------------------+              +-------------------------------+
    | Pin 4 (GPIO 2)       | -----------> | SWCLK (PA14)                  |
    | Pin 5 (GPIO 3)       | <----------> | SWDIO (PA13)                  |
    | Pin 2 (GPIO 1)       | -----------> | NRST  (复位引脚，强烈建议连接) |
    | Pin 3 (GND)          | -----------> | GND   (★必须共地★)             |
    | Pin 6 (GPIO 4 / TX)  | -----------> | Target RX (如 PA10，可选)     |
    | Pin 7 (GPIO 5 / RX)  | <----------- | Target TX (如 PA9，无线串口)   |
    +----------------------+              +-------------------------------+
```

| Pico 2 GPIO | 物理引脚编号 (Pin) | 信号功能 | 连接目标板引脚 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **`GPIO 1`** | **Pin 2** (左侧第2脚) | **RESET** | 目标板 **`NRST`** | 硬件复位输出（开漏，复位下连接必备） |
| **`GND`** | **Pin 3** (左侧第3脚) | **GND** | 目标板 **`GND`** | **系统公共参考地（绝对不能悬空）** |
| **`GPIO 2`** | **Pin 4** (左侧第4脚) | **SWCLK** | 目标板 **`SWCLK`** (`PA14`) | SWD 调试时钟线 (最高支持 25MHz) |
| **`GPIO 3`** | **Pin 5** (左侧第5脚) | **SWDIO** | 目标板 **`SWDIO`** (`PA13`) | SWD 双向半双工数据线 |
| **`GPIO 4`** | Pin 6 (左侧第6脚) | **UART TX** | 目标板 **`RX`** (`PA10`) | 调试器向目标板发送数据（可选） |
| **`GPIO 5`** | Pin 7 (左侧第7脚) | **UART RX** | 目标板 **`TX`** (`PA9`) | 目标板向调试器发送 `printf` 日志 |

## 三、 电源供电设计建议

1. **单 USB 统一供电**：
   * 将 Pico 2 的 `VBUS` (Pin 40, 5V) 与 ESP32-C5 的 `5V` 引脚相连。
   * 外部插入任意一条 Type-C 数据线（插在 Pico 2 或 ESP32-C5 均可）即可同时驱动整个系统。
2. **锂电池 / 移动电源供电**：
   * 搭配一枚 1S 3.7V 锂电池经由升压板提供 5V，即可实现完全脱离主机的全无线随身调试器。
3. **线长建议**：
   * Pico 2 与 ESP32-C5 间的 QSPI 杜邦线建议控制在 **10 cm 以内**（长线建议在底板走线并铺地，支持更高频率）。
   * Pico 2 连往目标板的 SWD 杜邦线建议控制在 **15 cm 以内**。
